# Demo Dataset Module

## Objective

Create realistic datasets for demonstrating the complete Zecpath AI hiring pipeline.

## Features

- Resume generation
- Job description generation
- Interview response generation
- Pipeline simulation
- Dataset validation
- Simulation summary generation

## Execution

Generate the demo dataset:

```bash
python -m demo_dataset.demo_runner
```

Run validation:

```bash
python -m demo_dataset.tests.test_demo_dataset
```

## Outputs

- Demo resumes
- Demo job descriptions
- Interview responses
- ATS results
- Screening results
- Interview reports
- Hiring reports
- Simulation summary
