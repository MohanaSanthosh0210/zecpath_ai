# Machine Test AI Framework

Version: 1.0

---

# Objective

Design an AI framework capable of evaluating practical technical skills
through structured machine tests.

This phase defines the evaluation architecture only.
Actual execution and code assessment are outside the scope of Day 50.

---

# Supported Task Types

- Coding Problems
- Debugging Tasks
- File-based Assignments
- Mini System Design

---

# Evaluation Metrics

The framework evaluates candidates using:

- Correctness
- Efficiency
- Code Quality
- Problem Solving

---

# Time-based Evaluation

Every task has an expected completion time.

Scores may later be adjusted based on:

- Submission time
- Difficulty level

---

# Expected Outputs

The framework will eventually generate:

- Machine Test Score
- Skill-wise Breakdown
- Machine Test Report

---

# Future Integration

Future modules may include:

- Code Execution Engine
- Automated Test Runner
- Static Code Analysis
- Plagiarism Detection

These modules are intentionally excluded from the design phase.
