# Improvement List

### ATS Engine

**Issue**

**Recommendation**

Introduce semantic skill matching using embedding-based similarity.

## Medium Priority

### Screening AI

**Issue**

**Recommendation**

Increase validation using confidence-aware thresholds.

**Issue**

**Recommendation**

Improve conversation memory and duplicate-question detection.

Difficulty progression can be smoother.

**Recommendation**

Implement adaptive difficulty selection based on previous answers.

### Decision AI

Confidence explanation can be more transparent.

**Recommendation**

Provide detailed reasoning for hiring decisions.
