Overview

This handbook gathers existing documentation and fills gaps with structured guidance for developers, maintainers, and integrators. Use the links above to jump to module-level details. Where implementation details exist in code, this handbook links to the authoritative source.

How to use this handbook

- Read the System Architecture first to understand components and dataflow.
- Consult API Design and ATS API Specification for integration points.
- Review Scoring & Data Models for how candidate signals are combined.
- Follow the Developer Onboarding and Deployment guides to run locally or in production.
