# Demo Dataset Guide

## Purpose

This dataset demonstrates the complete Zecpath AI hiring pipeline.

## Dataset Includes

- Demo resumes
- Job descriptions
- Interview responses
- ATS results
- Screening results
- Interview results
- Hiring reports

## Candidate Types

- Excellent
- Good
- Average
- Weak

## Job Roles

- Software Engineer
- Python Developer
- AI Engineer
- Data Analyst
- Full Stack Developer

## Output

The generated outputs simulate a complete hiring process from resume upload to final hiring recommendation.
