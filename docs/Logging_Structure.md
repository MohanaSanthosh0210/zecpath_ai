# Logging Structure

## API Logs

Capture:

- Endpoint
- Request Time
- Response Time
- Status Code

---

## Model Logs

Capture:

- Model Name
- Prediction
- Confidence Score
- Inference Time

---

## Error Logs

Capture:

- Error Code
- Error Message
- Severity
- Timestamp

---

## Audit Logs

Capture:

- Candidate ID
- Decision
- Score Changes
- Manual Overrides
- Timestamp
