# Final Output Guidelines

## Recruiter Reports

Every final report should include:

- Candidate Information
- ATS Score
- Screening Score
- HR Score
- Technical Score
- Overall Score
- Hiring Recommendation
- Confidence Level
- Risk Level
- Strengths
- Areas for Improvement

---

## JSON Standards

- UTF-8 encoding
- Four-space indentation
- Consistent key naming
- Standard data types

---

## Error Responses

Each error should include:

- Error Code
- Module
- Description
- Severity
- Resolution

---

## API Responses

Every API response should include:

- Status
- Message
- Data
- Timestamp (if applicable)

---

## Report Formatting

- Consistent section headings
- Readable score presentation
- Clear hiring recommendations
- Professional formatting
