# Recruiter Report Format

Each report contains the following sections.

---

## Candidate Information

Candidate ID

Applied Role

Overall Hiring Fit

Final Hiring Decision

---

## Evaluation Summary

ATS Summary

Screening Summary

HR Summary

Technical Summary

Behavior Summary

Integrity Summary

---

## Candidate Insights

Strengths

Weaknesses

Risk Indicators

---

## Recommendation

Final recruiter recommendation

Decision confidence

Executive summary
